# FamilyDiet MVP

## Goal
Локальний веб-застосунок ведення сімейної дієти: CRUD інгредієнтів/страв, календар меню на двох, трекінг ваги. Symfony 7 API + Vue 3 SPA + PostgreSQL 16 у Docker. Закупівлі — окремою ітерацією після основи (принцип ще обговорюється).

## Модель даних
- `family_member` — ім'я, цілі ккал/БЖВ (2 записи: чоловік, дружина)
- `ingredient` — назва, категорія (м'ясо/молочка/овочі/крупи/...), одиниця (г|мл|шт), КБЖВ на 100 г, вага 1 шт для штучних
- `dish` — код (B01...), назва, категорія (сніданок/обід/вечеря/перекус/дод.перекус), рецепт (текст), youtube_url, прапорець batch cooking
- `dish_portion` (dish + family_member) → `dish_portion_ingredient` (ingredient, amount) — окремі грамування для кожного; калорійність страви обчислюється
- `meal_plan_entry` — дата, family_member, слот (breakfast|lunch|dinner|snack|extra_snack), dish
- `weight_entry` — family_member, дата, вага (кг)
- (відкладено) `shopping_list` + `shopping_list_item` — формат обговорюється з дружиною
